# Guía verificada del portal local Moodle 5.3dev

Verificada en el entorno local de pruebas de Sprint 2, Moodle 5.3dev
(Build 20260911), el 2026-10-05. Interfaz de prueba en inglés. Alcance:
cuentas personales matriculadas, actividades de tipo Assignment visibles.
No afirma compatibilidad con otros portales, versiones, temas o tipos de actividad.

## Consultar una tarea y preparar la entrega

Entra al curso al que estás matriculado desde el portal y abre el enlace de la
actividad Assignment. La página de la actividad muestra Due (vencimiento),
Submission status (estado de entrega) y Grading status (estado de calificación).
Para preparar una entrega, pulsa Add submission. En el formulario de edición
completa los campos habilitados por el docente y pulsa Save changes. Regresa al
estado de entrega y comprueba el resultado: guardar cambios puede dejar un
borrador, dependiendo de la configuración de esa actividad. Esta guía no afirma
que guardar equivalga siempre a presentar definitivamente una tarea.

Recorrido observado con estudiante1 en Ejercicios de ecuaciones de Algebra 101:
el curso y la tarea se podían abrir, el botón Add submission llevaba al formulario
y el botón Save changes estaba presente. No se presentó una entrega durante la
verificación. La configuración de cada actividad determina campos, archivos y
necesidad de una presentación final.

## Límites

No se han verificado aquí recuperación de contraseña, configuración de pagos,
matrícula, creación de cursos ni procedimientos de administración. Para esas
preguntas no hay una guía de pasos verificada en este corpus. Este documento
explica el uso del portal: las fechas, estados, docentes y calificaciones personales
se deben consultar en vivo en Moodle, no deducirse de este ejemplo.
