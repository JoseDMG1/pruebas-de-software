# Scripts de reproducción

Estos archivos corresponden a las rutas dev/validation y dev/moodle del proyecto. Se ejecutan dentro del checkout completo, con sus dependencias, servicios y configuración local; este directorio no contiene el aplicativo ni credenciales.

No ejecutar los coordinadores sobre las salidas existentes: las evidencias se preservan y los archivos no se sobrescriben. Para la reprueba utilizar capacity_chat.py con un nombre de etapa y salida nuevos, después de disponer de cuota suficiente. Ver Rendimiento ampliado - resultados.md en la carpeta superior.

Los scripts entregados incluyen mejoras de guardas, presentación y lint posteriores a las mediciones. Los resultados conservan su fecha, configuración y los hashes disponibles de cada ejecución.
